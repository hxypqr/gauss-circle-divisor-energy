# 圆内整点／除数问题稿件的 Lean 形式化

**状态：部分内部证明已完成，整篇尚未完成。这里没有证明主定理 1.1，也没有证明第一间距定理 1.2。**

本工程对应 *Amplitude-dependent first spacing and the circle and divisor problems*，2026-09-06 稿，21 页。原件见 [历史稿件目录](manuscript/)。其指数为

\[
\vartheta=(33333-8\sqrt{64515})/99856.
\]

Lean 已证明

\[
0.3134615421<\vartheta<0.3134615422,
\]

以及整个困难区间上的优化不等式，并证明内点 `x0` 达到该值。这是稿件内部的精确计算；它本身不能证明圆问题的误差界。

```text
lake build
```
